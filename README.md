Solara Nights is an original top-down open-world crime game: a sun-soaked coastal city you explore on foot and by car, with traffic, pedestrians, a five-star wanted system and police response, story missions, combat, a HUD with minimap, and save/load — built to run offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080
